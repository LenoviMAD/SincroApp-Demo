1 Descripción general de la aplicación

SincoApp es una aplicación de escritorio para Windows que opera de forma automática en segundo plano (en la bandeja del sistema). Su función es sincronizar los datos de su empresa con el sistema central, transmitiendo y descargando información en intervalos de tiempo configurables.

La aplicación monitorea una carpeta de entrada, detecta los archivos nuevos, los envía al servidor y los mueve a la carpeta Procesados (si fue exitoso) o Errores (si falló).

Tipos de datos sincronizados
Productos · Clientes · Stock · Repartos
Operación
Automática en segundo plano, con intervalos configurables
Resultado exitoso
El archivo se mueve a la carpeta Procesados
Resultado con error
El archivo se mueve a la carpeta Errores + mensaje en el log
2 Proceso de carga de archivos
Flujo paso a paso
  1. 1 Prepare el archivo CSV o JSON según el formato indicado en este manual.
  2. 2 Asegúrese de que el nombre del archivo contenga la palabra clave correcta (ver tabla a continuación).
  3. 3 Copie el archivo en la carpeta de entrada configurada en SincoApp.
  4. 4 La aplicación detecta y procesa el archivo automáticamente en el próximo ciclo de transmisión.
  5. 5 Si el archivo es correcto → se mueve a la carpeta Procesados.
  6. 6 Si el archivo tiene errores → se mueve a Errores y queda registrado en el log de la aplicación.

3 Formato general de los archivos CSV
CaracterísticaValor requeridoDetalle y ejemplos
Tipo de archivo.csv (texto plano)No se aceptan .xlsx, .xls, .ods u otros formatos de hoja de cálculo
Codificación de textoUTF-8Evita caracteres extraños en tildes y ñ. En Excel: Guardar como → CSV UTF-8
Separador de columnasPunto y coma ;No usar coma (,) ni tabulación. Cada columna se separa con ;
Separador decimalPunto . (formato inglés)Correcto: 1500.75 · Incorrecto: 1500,75
Primera filaEncabezado (se ignora)La primera fila siempre es de títulos y el sistema la omite. Los datos comienzan en la fila 2
Valores booleanosTrue o FalseCon mayúscula inicial, en inglés. No usar: 1/0, SI/NO, sí/no, verdadero/falso
Campos opcionales vacíosDejar vacío entre separadoresDos punto y coma seguidos: ;; indica campo vacío
Texto con punto y comaEncerrar entre comillas "…"Si un texto contiene ; se escribe: "Texto con; coma"
Filas vacíasSe ignoran automáticamenteLas líneas en blanco dentro del archivo son omitidas sin error
Orden de columnasFijo según este manualEl sistema lee por posición (columna 0, 1, 2…), no por nombre. No reordenar
Estructura típica del archivo:
Columna1;Columna2;Columna3;... ← Fila 1: encabezado (ignorado) Valor1;Valor2;Valor3;... ← Fila 2: primer registro Valor1;Valor2;Valor3;... ← Fila 3: segundo registro
Importante sobre decimales: El sistema usa formato numérico inglés (InvariantCulture). El separador decimal es el punto (.) y la coma nunca se acepta como decimal. Si exporta desde Excel con configuración regional española, el sistema rechazará los valores numéricos. Antes de importar, verifique que todos los números tengan punto decimal.
Recomendación: Abra el archivo con Notepad++ antes de importarlo. Podrá verificar la codificación en la barra de estado (debe decir "UTF-8") y buscar comas decimales con Ctrl+F para reemplazarlas por puntos.

9 Recomendaciones prácticas
Preparación del archivo en Excel
  • Al exportar desde Excel, elija CSV UTF-8 (delimitado por comas) y luego abra el archivo con Notepad++ para reemplazar las comas por punto y coma. También puede usar Buscar y reemplazar (Ctrl+H) para cambiar el separador antes de exportar.
  • Para el separador decimal, vaya a Opciones de Excel → Avanzadas y desactive "Usar separadores del sistema". Configure el separador decimal como . (punto) antes de exportar.
  • No incluya fórmulas en las celdas del CSV. Asegúrese de que todos los valores sean texto o número puro antes de exportar.
  • Si su sistema de gestión (ERP, facturación) puede exportar directamente al formato requerido, configúrelo para hacerlo y evite pasos manuales que puedan introducir errores.
Verificación antes de importar
  • Abra el archivo con Notepad++ (gratuito) antes de copiarlo a la carpeta de entrada. Verifique que la codificación en la barra de estado diga UTF-8.
  • Confirme que el separador de columnas es ; (punto y coma) y no coma.
  • Busque comas decimales con Ctrl+F y reemplácelas por puntos si las encuentra.
  • Cuente las columnas de la primera fila de datos y compárelas con la cantidad esperada según este manual.
Nomenclatura y gestión de archivos
  • Use nombres descriptivos con fecha: productos_20260520.csv facilita el seguimiento y el diagnóstico de problemas.
  • No envíe el mismo archivo dos veces si ya fue procesado exitosamente. Podría generar duplicados de datos en el sistema.
  • Si necesita corregir y reenviar un archivo, asegúrese de que el original ya haya sido movido a Procesados o Errores antes de poner el nuevo en la carpeta de entrada.
  • Para repartos, use un número de reparto único por día y por fletero para evitar colisiones.
Flujo de trabajo recomendado
  1. 1 Genere o exporte el archivo desde su sistema de gestión (ERP / software de facturación).
  2. 2 Abra el archivo en Notepad++ y verifique formato, codificación y separadores.
  3. 3 Copie el archivo en la carpeta de entrada de SincoApp.
  4. 4 Espere el ciclo de transmisión automática (el intervalo está configurado en la pantalla principal de la app).
  5. 5 Revise la carpeta Procesados: si el archivo está ahí, la carga fue exitosa.
  6. 6 Si el archivo está en Errores, abra el log de la aplicación para ver el detalle del error y corrija el archivo.
Herramienta gratuita recomendada: Notepad++ (notepad-plus-plus.org) permite abrir archivos CSV, ver la codificación de caracteres, buscar y reemplazar separadores, y verificar el formato antes de importar. Es una herramienta esencial para trabajar con archivos de texto en Windows.

10 Observaciones técnicas

Esta sección documenta comportamientos específicos del sistema que son relevantes conocer para evitar errores:

Comportamiento del procesamiento de archivos
  • El tipo de archivo se determina únicamente por el nombre. Si el nombre no contiene ninguna de las palabras clave reconocidas, el archivo es ignorado silenciosamente sin generar error visible.
  • Las filas completamente vacías dentro del archivo son ignoradas automáticamente.
  • Los espacios al inicio y al final de cada campo son eliminados automáticamente. Aun así, es recomendable no incluirlos para mantener los datos limpios.
  • Si ya existe un archivo con el mismo nombre en la carpeta de destino (Procesados o Errores), el sistema agrega un timestamp al nombre para evitar sobrescritura. Ejemplo: productos_20260520_20260520_163045_123.csv
Sobre los valores numéricos opcionales vacíos
  • Un campo numérico opcional que esté vacío es tratado como 0 por el sistema.
  • Un campo booleano vacío es simplemente ignorado (queda con el valor por defecto del modelo).
  • Las coordenadas GPS (Latitud/Longitud) aceptan valores negativos con punto decimal. Ejemplo: -34.603722
Listas de precios y asignación a clientes
  • El sistema soporta hasta 8 listas de precios por producto (L1 a L8) con dos variantes: precio final (con IVA) y precio neto (sin IVA).
  • El precio que ve el vendedor para un cliente específico es el que corresponde al campo ListaDePrecio asignado en el archivo de Clientes. Por ejemplo, si un cliente tiene ListaDePrecio = 3, el sistema usará el valor de PrecioUnitarioFinalL3.
  • Solo es necesario completar las listas de precios que su empresa efectivamente utilice.
JSON de Repartos — Nombre del campo FelterosID
En el archivo JSON de Repartos, el campo del fletero se llama FelterosID (con "F", no "Fl"). Este es el nombre exacto que debe usar en el JSON. Si escribe FleterosID u otra variante, el sistema no lo reconocerá y generará un error de validación.
Gestión de Vendedores
La gestión de vendedores (altas, modificaciones, asignación de claves) se realiza exclusivamente desde el portal web de administración. SincoApp no procesa archivos de vendedores. Para agregar o modificar un vendedor, acceda al portal web y utilice la sección correspondiente.
